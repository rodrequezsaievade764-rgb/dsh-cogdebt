# dsh-cogdebt

认知债务追踪。给 DeepSeek Harness 用。

## 它记的不是待办

待办清单管的是**承诺**：我答应了，要去做。
认知债管的是**逃避**：这段我没看懂，先往下翻；这个报错我没查，先注释掉；这篇文章我扫两眼觉得费劲，收藏了。

它们不会因为你没记就消失。它们会在某个时刻回来找你 —— 面试前、改需求时、别人问起时。

## 核心就一个公式

```
利息 = 痒度 × 拖了几天 × 逃避系数
```

**痒度**是你自己标的重要度，1-3。
**天数**从记下那天算起，结清就冻结，不再涨。
**逃避系数**看当初为什么跳过：

| 当初为什么跳过 | 系数 | 为什么 |
|---|---|---|
| 不想碰 | 2.0 | 越不想看的事，利滚利最快 |
| 看不懂 | 1.6 | 认知上够不着，越放越远 |
| 被打断 | 1.0 | 纯粹被截断，利不算高 |
| 没时间 | 0.7 | 忙不是债，但也是债 |
| 说以后再 | 0.5 | 最轻，多数会自己消失 |

不搞复利，不搞指数。那些数字好看但没法解释。
线性够用：拖两周，利息翻倍，这就足以让你想动它。

## 两种结清，别混

- **还清**（`paid`）—— 真回去弄懂了
- **划掉**（`dropped`）—— 想通了，不值得懂，主动止损

两个都算结清，统计分开算。
**划掉不是丢脸，是止损。** 一个永远还不完的账本只会让你再也不打开它。

## 四个工具

| 工具 | 干什么 |
|---|---|
| `cogdebt_owe` | 记一笔。`topic` 写清是什么，`reason` 写为什么跳过，`weight` 1-3 |
| `cogdebt_pay` | 结一笔。`mode=paid` 还清 / `mode=dropped` 划掉 |
| `cogdebt_list` | 看账本。默认按利息从高到低，最多 `limit` 笔（默认 8）；`all=true` 时按时间倒序，最多 `allLimit` 笔（默认 50） |
| `cogdebt_stat` | 总览：总利息、哪类欠得最狠、最久那笔拖了多久 |

`reason` 是可选枚举，只认 `avoid / hard / interrupted / time / later` 与它们的中文别名。
留空按 `later` 记；写了但认不出来会直接报错，不会偷偷记成「说以后再」。

## 测试

```bash
node --test "test/**/*.test.js"
```

测试全离线，不依赖宿主：`lib/**` 是纯函数与一个最小 `ctx` 替身。
`node --test` 是 Node 内置的，库里零运行时依赖。

93 个用例，分五层：`store`（读写、坏条目归一化）、`interest`（利息公式与汇总）、`tool`（工具壳的兜错）、`index`（四个工具的行为与参数边界）、`package`（清单字段与装配）。存储用 `mkdtempSync` 造临时目录，不碰真实账本。

## 装

```bash
pnpm add dsh-cogdebt
# 或从本地目录
pnpm add file:/path/to/dsh-cogdebt
```

再加进 profile 的 `dsh.profile.bundles`，重载 harness。
插件自带 `cordis.patch.yml`，会自动插一条记录。

## 配置

```yaml
config:
  scanIntervalMinutes: 60    # 每小时看一次账
  quietHours: [23, 8]        # 这期间不催
  nagCooldownHours: 48       # 同一笔两天才催一次
  maxPerScan: 2              # 一次最多催两笔
  notifyService: ''          # 走哪个 DSH 服务的 send()
  notifyTo: ''               # 推给谁
  webhookUrl: ''             # 或者 POST 到这儿
```

催办门槛是利息 ≥ 3。刚记下的东西不算债，别自己吓自己。
同理，账上所有债的利息都是 0 时，`cogdebt_stat` 不会报「欠得最狠的是 X」——一个字都没拖，谈不上狠。

推送两条路：`notifyService` 填一个提供 `send({target, text})` 的 DSH 服务名；
或者 `webhookUrl` 直接 POST。都没配就只写日志，不报错。

## 数据

`~/.dsh/cogdebt/debts.json`，纯 JSON。
坏文件不覆盖，改名成 `.broken-<时间戳>` 留档再重开。

## 为什么不接日历 / 笔记 / 浏览器

接得上，但接上就有人要权限。
这个插件的价值不在「自动抓」，在「你自己承认」——
你亲手记一笔「这段我跳过了」，比任何自动解析都准。

二期再考虑从对话里捞：「这个我以后再研究」。

## 状态

0.2.0。这一版没有加新工具，修的全是账本算错的地方：

- 理由拼错会被静默记成「明天再说」，按 0.5 收利息——你以为标了「太难」，账本按「往后拖」算
- 利息全为 0 时，汇总仍会报「欠得最狠的是 X」
- 汇总文案与利息合计各用各的时钟，「最久拖了 N 天」能差出上千天
- `limit: 0` 被吞成默认 8，`all` 分支的上限被放大 3 倍，与说明不符
- 拼错状态的历史脏数据会同时从利息排序、汇总、还款三处消失
